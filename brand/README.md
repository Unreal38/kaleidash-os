# KaleidashOS brand

KaleidashOS combines fast, responsive window movement with a desktop palette that adapts to the current wallpaper.

## Identity

- Name: **KaleidashOS**
- Short name: **Kaleidash**
- Technical ID: `kaleidash`
- Tagline: **Every wallpaper, a new desktop.**
- Foundation: Fedora, Niri, and Noctalia

## Logo system

The primary logo is the **Kinetic K**. Its sharp diagonal strokes express fast window switching, while its overlapping color facets represent the desktop palette changing with the wallpaper.

| Asset | Purpose |
| --- | --- |
| `logo/kaleidash-mark.svg` | Primary full-color mark |
| `logo/kaleidash-mark-mono.svg` | Single-color and high-contrast use |
| `logo/kaleidash-mark-compact.svg` | Fastfetch and other small terminal contexts |

The primary geometry must remain recognizable without color. Wallpaper integration should recolor the facets without changing their positions or silhouette.

The folded-ribbon concept is reserved for future animation during login, wallpaper transitions, and promotional motion graphics. It is not a replacement static logo.

## Reference palette

The included gradients demonstrate the color behavior rather than prescribe a permanent palette:

- Cyan: `#19d9f3`
- Blue: `#2468f2`
- Violet: `#7138f4`
- Magenta: `#f31cad`
- Coral: `#ff775c`

Production integrations should replace these colors with an accessible selection derived from the current wallpaper.
